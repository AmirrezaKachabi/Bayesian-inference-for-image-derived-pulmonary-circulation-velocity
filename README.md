# MB / C1 — Bayesian PC-MRI velocity-profile inference

A self-contained, cleaned Jupyter notebook that generates the **C1 (MB canine) results using the corrected DRAM sampler** for *A Bayesian Framework for Uncertainty-Aware Estimation of Main Pulmonary Artery Velocity Profiles from Phase-Contrast MRI*.

It uses 2D phase-contrast MRI magnitude/phase DICOMs and pixel coordinates exported from ImageJ to fit an elliptical pulmonary-artery cross-section, compute a 15-bin normalized radial profile, and estimate Power-law and Womersley posterior distributions with **correct two-stage delayed-rejection adaptive Metropolis (DRAM)**.

## Setup and execution

Requires Python 3.10+.

```bash
python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter notebook MB_C1_Corrected_DRAM_GitHub_CLEAN.ipynb
```

In the notebook, set `SMOKE_TEST = True` for a quick functionality check, then set `SMOKE_TEST = False` and **Run All** for final results. Full mode uses 4 chains × 60,000 iterations, discards 10,000 iterations per chain, uses 1,000 normalization bootstraps, and 3,000 posterior draws for UQ bands. Runtime depends on the computer.

Input ROI CSV: the first two columns must contain **ImageJ x and y pixel coordinates** (zero-based, with x = image column, y = image row). These coordinates must refer to the same image dimensions as both DICOM files. The notebook uses `PixelSpacing` from the magnitude DICOM for the physical-radius calculation.

## Generated outputs

All generated files are written to `results_MB_C1/` (excluded from Git):

- `C1_binned_data.csv`: 15-bin normalized data and observational uncertainty.
- `C1_Power_law_chains.npz`, `C1_Womersley_chains.npz`: all retained corrected-DRAM posterior chains.
- `C1_posterior_summary.csv`, `C1_convergence_diagnostics.csv`: MAP, posterior moments, 95% intervals, R-hat and ESS.
- `C1_*_posterior_*.pdf/png`: marginal KDE plots **without** mean/CI reference lines.
- `C1_*_trace.pdf`: trace plots.
- `C1_*_fit_with_UQ.pdf/png`: MAP fit (black), 95% credible band (dark gray), 95% prediction band (light gray), C1 observations (blue).
- `C1_*_UQ_curves.csv`: prediction and uncertainty curves on the complete radius 0–1.
- `C1_fit_metrics.csv`, `C1_regional_wRMSE.csv`, `C1_Table2_row.csv`.

Review R-hat and effective sample size for every parameter before interpreting the posteriors. Do not use smoke-test samples as scientific results.

## Important methodological details

- **All results generated by this repository use the corrected two-stage DRAM sampler**, including posterior summaries, MAP estimates, uncertainty bands, and fit metrics. The sampler uses the full delayed-rejection acceptance ratio, including first-stage proposal densities and forward/reverse rejection probabilities. No original nonstandard-sampler posterior samples are used in the final analysis.
- Proposals are tuned **during burn-in only** and fixed for the retained posterior samples. The initial proposal covariance is estimated from local numerical curvature of the posterior; no samples from the original nonstandard sampler are used.
- The MB preprocessing, normalization, and prior definitions are retained from the supplied analysis notebook. Specifically, its `compute_ubar_from_profile` function evaluates `2 * trapz(r_vals * I_vals, r_vals)`; the manuscript writes the physically area-weighted integral `2 * integral(r * I(r) dr)`. These expressions are **not identical**. The notebook preserves the supplied preprocessing implementation. Check this distinction when documenting the data-derived prior center.
- The MB preprocessing computes `alpha_phys = sqrt(a_fit*b_fit) * PixelSpacing[0] / 1000 * sqrt((2*pi/0.5)/2.91e-6)`. The published Table 2 reports **C1 alpha_phys = 19.3**. If your recalculation differs, inspect original geometry, DICOM pixel spacing, and physiological cycle duration; do not overwrite the calculation merely to force the table value. The notebook offers an explicitly labeled `ALPHA_PRIOR_CENTER_OVERRIDE` only if the original prior center can be independently documented.
- The Power-law model-discrepancy prior scale is **0.05**, and the Womersley scale is **0.03**; these settings are retained.
- This repository reproduces the **corrected-DRAM analysis for MB/C1 only**. It does not regenerate the other eight subjects. Stochastic posterior draws may vary across runs, even with consistent posterior summaries.

## Publishing DICOM files safely

**Do not upload original clinical or animal-study DICOM files without verifying permission and de-identification.** DICOMs can contain identifying fields (e.g. PatientName, PatientID, StudyDate, InstitutionName, AccessionNumber), private vendor tags, and identifying information embedded in image pixels. Inspect and de-identify both files using your institution's approved process and retain required technical attributes such as `PixelSpacing`, pixel data, image dimensions, and decoding metadata. Ensure study approvals and data-sharing agreements allow public redistribution. ImageJ coordinates can also be subject to data-use restrictions. GitHub history persists after deletion, so verify before the first push.
